# Pixel Phone

A smartphone UI system developed using Unity and C#, designed to simulate an interactive in-game smartphone experience.

The project features multiple applications, including a music player, contacts interface, and messaging system. It demonstrates UI management, application navigation, event handling, and data persistence within Unity.

## Features

- Home Screen: Central interface for accessing different applications.
- Music Player: Browse available songs and access the Now Playing interface.
- Caller App: Interactive contacts interface.
- Messaging System: Unlock messages through in-game events.
- Notification System: Visual notification badges and audio notifications when new messages become available.
- Message Persistence: Uses Unity PlayerPrefs to retain collected message states between sessions.

## Built With

## Getting Started

To explore or run this project locally:

1. Clone the repository: git clone https://github.com/ArpitGuptrishi/Pixel-Phone.git

2. Open Unity Hub.
3. Select Add Project from Disk.
4. Navigate to the cloned repository folder.
5. Open the project using the appropriate Unity Editor version.
6. Open the main scene and press Play.

## Technical Highlights

Some of the concepts explored during development:

- Modular UI navigation and screen management.
- Communication between game systems and UI components.
- Event-driven message unlocking.
- Runtime UI activation and deactivation.
- Persistent data storage using PlayerPrefs.
- Audio feedback and notification handling.
